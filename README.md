# AutoSell Car Dealership Website

AutoSell is a responsive multi-page car dealership website developed as an academic UI and front-end project.

The project focuses on clear navigation, structured information architecture, responsive interface design, and interactive vehicle browsing.

## Features

- Responsive multi-page web interface
- Landing page
- Vehicle listing page
- Individual car detail page
- Login and registration pages
- Interactive filtering by brand, color, and price
- Structured navigation and user-oriented information presentation

## Technologies

- HTML
- CSS
- JavaScript
- Figma

## Project Context

This project was designed and developed in 2023 as an academic UI/web design project.

The interface content is in Persian, while the project demonstrates the underlying front-end structure, responsive design, interaction patterns, and information architecture.
